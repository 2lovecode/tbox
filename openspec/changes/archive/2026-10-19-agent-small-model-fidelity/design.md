## Context

小模型档把全部注册工具写进系统提示。1.7B 上下文被撑满后，`strategy_reset` 只留 system 和当前用户句，工具结果消失，模型会再调一次。`escape_json` 用严格 `serde_json::from_str`，输入若已是 `{\"a\":1}` 会在第 2 列失败，且没有「用原文重试」的提示。

## Goals / Non-Goals

**Goals:**

- 重置后模型仍看得到本轮用户原文和最近一次工具结果或错误。
- 多写一层反斜杠时，`json.escape` 要么剥层后转义成功，要么返回含「不要再多写反斜杠」的错误。
- 命中技能时，小模型/轻量档目录只含这些 `tool_id`。未命中时仍列出全部工具。
- 同一模型回合内，相同 name + arguments 只 dispatch 一次。

**Non-Goals:**

- 不改技能检索排序，不删工具注册。
- 不改云端默认提示（本来就没有工具目录）。
- 不把压缩后的视图写回用户可见历史。

## Decisions

1. 重置保留尾部「assistant tool_calls + 紧随的 tool 消息」。单条结果超过 2000 字时只留前 800 字，并写明不要用相同参数再调。错误文本通常更短，会整段留下。
2. `escape_json` 在严格解析成功时按原文转义，保留空白。失败时走已有的宽松剥层，再对解析出的值做一次转义。弯引号 `“”` 先换成 `"`。
3. 目录过滤在 `build_small_prompt` / `build_lite_prompt` 内调用 `retrieve_skills`，与循环里的技能装载使用同一函数。只收录注册表里存在的 id。
4. 去重发生在执行前，保留第一次出现的 call id，避免协议上的悬空结果。

## Risks / Trade-offs

- 技能 `tool_id` 漏登记时，对应工具不会出现在本轮目录里。未命中任何技能时回退全量目录。
- 重置仍保留一条工具结果，极端大结果只留开头，模型可能看不到尾部。完整结果仍在轨迹里。
